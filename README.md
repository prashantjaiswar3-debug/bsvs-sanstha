BSVS — Separate Sanstha Website

Files:
- index.html: standalone Hindi-first institutional website
- assets/style.css: responsive styling and visual layout
- assets/site.js: mobile navigation and footer year

How to preview:
Open index.html in a modern browser. Internet access is required for the optional Google Fonts; the site otherwise works without external images because its hero illustration uses CSS and emoji.

Before publishing:
1. Replace bracketed registered office, email and phone placeholders.
2. Add verified registration number, registration date, official logo and approved office-bearer details.
3. Review proposed structure and programme descriptions against the registered constitution/bylaws and applicable law.
4. Connect the contact form to a secure backend or trusted form service. It is currently a demo and does not send messages.

GitHub Pages:
Upload index.html, assets/ and README.md to the root of a separate repository, then Settings > Pages > Deploy from a branch > main > /(root).
